## Slide 2: The Problem
*   **Fragmented Systems:** Lack of integration between attendance, marks, and admissions.
*   **Manual Overhead:** Teachers spend excessive time on repetitive tasks (attendance, quiz prep).
*   **Reactive Monitoring:** Student performance issues are usually identified too late.
*   **Information Overload:** Difficulty in extracting insights from large textbooks.

---

## Slide 3: Our Solution
*   **Unified Platform:** A single source of truth for Students, Faculty, and Admins.
*   **Proactive Analytics:** AI-powered student "At-Risk" prediction.
*   **Smart Learning:** RAG-based AI Quiz Generator for personalized assessments.
*   **Modern UX:** Responsive, professional dashboard with real-time updates.

---

## Slide 4: Tech Stack
*   **Frontend:** React.js, Tailwind CSS (Modern, Responsive UI).
*   **Backend:** Node.js + Express (Robust API management).
*   **Database:** PostgreSQL + Supabase (Scalable & Secure storage).
*   **AI Engine:** FastAPI (Python), Google Gemini, FAISS (Vector DB for RAG), Scikit-Learn.

---

## Slide 5: Core Feature: AI Student Risk Analysis
*   **Predictive Modeling:** Uses Logistic Regression to identify students struggling academically.
*   **Parameters:** Attendance, Marks, Assignment completion, and Previous GPA.
*   **Outcome:** Early intervention alerts for faculty to improve student success rates.

---

## Slide 6: Core Feature: Hybrid RAG Quiz Engine
*   **Full Context:** Upload any textbook or PDF.
*   **Hybrid Architecture:** 
    *   **Internal Knowledge:** PDF Extraction -> Chunking -> Vector store (FAISS).
    *   **Global Knowledge:** Automated Retrieval from **Wikipedia**, **Web Search**, and **GeeksforGeeks**.
*   **Accuracy:** Reduces hallucinations by grounding AI in both specialized and general knowledge.
